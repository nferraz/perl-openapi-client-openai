=head1 NAME

OpenAPI::Client::OpenAI::Path::organization-spend_limit - Documentation for the /organization/spend_limit path.

=head1 OPERATIONS

=head2 DELETE /organization/spend_limit

=head3 Deleteorganizationspendlimit

  $client->deleteorganizationspendlimit({
      body => { ... },
  });

Delete the organization's hard spend limit.

=head4 Responses

B<200 - Hard spend limit deleted successfully.>

Content-Type: application/json

Example:

    {
       "deleted" : false,
       "object" : "organization.spend_limit.deleted"
    }

=head2 GET /organization/spend_limit

=head3 Getorganizationspendlimit

  $client->getorganizationspendlimit({
      body => { ... },
  });

Get the organization's hard spend limit.

=head4 Responses

B<200 - Hard spend limit retrieved successfully.>

Content-Type: application/json

Example:

    {
       "currency" : null,
       "enforcement" : {
          "status" : null
       },
       "interval" : null,
       "object" : "organization.spend_limit",
       "threshold_amount" : 0
    }

=head2 POST /organization/spend_limit

=head3 Updateorganizationspendlimit

  $client->updateorganizationspendlimit({
      body => { ... },
  });

Create or replace the organization's hard spend limit.

=head4 Responses

B<200 - Hard spend limit created or replaced successfully.>

Content-Type: application/json

Example:

    {
       "currency" : null,
       "enforcement" : {
          "status" : null
       },
       "interval" : null,
       "object" : "organization.spend_limit",
       "threshold_amount" : 0
    }

=head1 SCHEMAS

=head2 OrganizationSpendLimitDeletedResource

Properties:

=over

=item * C<deleted> (boolean, required) - Whether the hard spend limit was deleted.

=item * C<object> (string, required) - The object type, which is always C<organization.spend_limit.deleted> .

Allowed values: organization.spend_limit.deleted

Default: organization.spend_limit.deleted

=back

=head2 OrganizationSpendLimitResource

Properties:

=over

=item * C<currency> (SpendLimitCurrency, required) - The currency for the threshold amount. Currently, only C<USD> is supported.

See L</SpendLimitCurrency> below for shape.

=item * C<enforcement> (SpendLimitEnforcement, required) - The current enforcement state of the hard spend limit.

See L</SpendLimitEnforcement> below for shape.

=item * C<interval> (SpendLimitInterval, required) - The time interval for evaluating spend against the threshold. Currently, only
C<month> is supported.

See L</SpendLimitInterval> below for shape.

=item * C<object> (string, required) - The object type, which is always C<organization.spend_limit> .

Allowed values: organization.spend_limit

Default: organization.spend_limit

=item * C<threshold_amount> (integer, required) - The hard spend limit amount, in cents.

=back
