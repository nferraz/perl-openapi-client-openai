=head1 NAME

OpenAPI::Client::OpenAI::Path::chatkit-sessions-session_id-cancel - Documentation for the /chatkit/sessions/{session_id}/cancel path.

=head1 DESCRIPTION

This document describes the API endpoint at C</chatkit/sessions/{session_id}/cancel>.

=head1 PATHS


=head2 C<POST /chatkit/sessions/{session_id}/cancel>

Cancel an active ChatKit session and return its most recent metadata.

Cancelling prevents new requests from using the issued client secret.



=head3 Operation ID

C<CancelChatSessionMethod>

    $client->CancelChatSessionMethod( ... );

=head3 Parameters

=over 4

=item * C<session_id> (in path) (Required) - Unique identifier for the ChatKit session to cancel.

Type: C<string>



=back
