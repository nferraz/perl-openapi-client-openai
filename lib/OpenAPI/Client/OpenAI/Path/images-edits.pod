=head1 NAME

OpenAPI::Client::OpenAI::Path::images-edits - Documentation for the /images/edits path.

=head1 DESCRIPTION

This document describes the API endpoint at C</images/edits>.

=head1 PATHS


=head2 C<POST /images/edits>

Creates an edited or extended image given one or more source images and a prompt. This endpoint supports GPT Image models (C<gpt-image-1.5>, C<gpt-image-1>, C<gpt-image-1-mini>, and C<chatgpt-image-latest>) and C<dall-e-2>.


You can call this endpoint with either:

=over

=item -

C<multipart/form-data>: use binary uploads via C<image> (and optional C<mask>).


=item -

C<application/json>: use C<images> (and optional C<mask>) as references with either C<image_url> or C<file_id>.


=back

Note that JSON requests use C<images> (array) instead of the multipart C<image> field.



=head3 Operation ID

C<createImageEdit>

    $client->createImageEdit( ... );

=head3 Parameters

=over 4

=back

=head3 Request Body
  
=head3 Content Type: C<application/json>

    
      JSON request body for image edits.

Use `images` (array of `ImageRefParam`) instead of multipart `image` uploads.
You can reference images via external URLs, data URLs, or uploaded file IDs.
JSON edits support GPT image models only; DALL-E edits require multipart (`dall-e-2` only).


      

=head4 Models

The model to use for image editing.

=over 4
      
=item * C<gpt-image-1.5>

=item * C<gpt-image-1>

=item * C<gpt-image-1-mini>

=item * C<chatgpt-image-latest>

=back
      
      
Example:

    {
       "background" : "transparent",
       "images" : [
          {
             "file_id" : "file-abc123",
             "image_url" : "https://example.com/source-image.png"
          }
       ],
       "mask" : {
          "file_id" : "file-abc123",
          "image_url" : "https://example.com/source-image.png"
       },
       "model" : "gpt-image-1.5",
       "moderation" : "auto",
       "n" : 1,
       "output_compression" : 100,
       "output_format" : "png",
       "prompt" : "Add a watercolor effect and keep the subject centered",
       "quality" : "high",
       "size" : "1024x1024",
       "stream" : false,
       "user" : "user-1234"
    }
