=head1 NAME

OpenAPI::Client::OpenAI::Path::realtime-client_secrets - Documentation for the /realtime/client_secrets path.

=head1 DESCRIPTION

This document describes the API endpoint at C</realtime/client_secrets>.

=head1 PATHS


=head2 C<POST /realtime/client_secrets>

Create client secret


Create a Realtime client secret with an associated session configuration.



=head3 Operation ID

C<create-realtime-client-secret>

    $client->create-realtime-client-secret( ... );

=head3 Parameters

=over 4

=back

=head3 Request Body
  
=head3 Content Type: C<application/json>

    
      Create a session and client secret for the Realtime API. The request can specify
either a realtime or a transcription session configuration.
[Learn more about the Realtime API](https://platform.openai.com/docs/guides/realtime).


      
      
Example:

    {
       "expires_after" : null
    }


             

=head3 Responses


=head4 Status Code: C<200>

Client secret created successfully.
