=head1 NAME

OpenAPI::Client::OpenAI::Path::realtime-calls-call_id-reject - Documentation for the /realtime/calls/{call_id}/reject path.

=head1 DESCRIPTION

This document describes the API endpoint at C</realtime/calls/{call_id}/reject>.

=head1 PATHS


=head2 C<POST /realtime/calls/{call_id}/reject>

Decline an incoming SIP call by returning a SIP status code to the caller.



=head3 Operation ID

C<reject-realtime-call>

    $client->reject-realtime-call( ... );

=head3 Parameters

=over 4

=item * C<call_id> (in path) (Required) - The identifier for the call provided in the
[`realtime.call.incoming`](/docs/api-reference/webhook-events/realtime/call/incoming)
webhook.

Type: C<string>



=back

=head3 Request Body
  
=head3 Content Type: C<application/json>

    
      Parameters used to decline an incoming SIP call handled by the Realtime API.

      
      
Example:

    {
       "status_code" : 486
    }


             

=head3 Responses


=head4 Status Code: C<200>

Call rejected successfully.
