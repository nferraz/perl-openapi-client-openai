=head1 NAME

OpenAPI::Client::OpenAI::Path::content_provenance_checks - Documentation for the /content_provenance_checks path.

=head1 OPERATIONS

=head2 POST /content_provenance_checks

=head3 Createcontentprovenancecheck

  $client->createcontentprovenancecheck({
      body => { ... },
  });

Check whether an image or audio file contains known OpenAI provenance signals.
L<Learn more about content provenance|https://platform.openai.com/api/docs/guides/content-provenance>
.

If C<not_detected> , it means the tool did not find supported signals in the
uploaded file. The content could still have been generated by OpenAI if the
metadata was stripped or has evidence of tampering, the watermark was
degraded, it comes from a legacy generation model, or it was created before
provenance signals were available. Content could also still be AI-generated by
another company's model, which the tool currently does not detect.

=head4 Responses

B<200 - Success>

Content-Type: application/json

Example:

    {
       "created_at" : 0,
       "object" : "content_provenance_check",
       "results" : [
          {
             "generated_at" : "string",
             "issuer" : "string",
             "model" : "string",
             "outcome" : "detected",
             "type" : "c2pa",
             "validation_state" : "trusted"
          }
       ]
    }

=head1 SCHEMAS

=head2 CreateContentProvenanceBody

Properties:

=over

=item * C<file> (string, required) - The image or audio file to check for supported OpenAI provenance signals.

=back

=head2 ProvenanceCheckObject

See L<https://platform.openai.com/docs/api-reference> for details.

=head2 ProvenanceResource

Properties:

=over

=item * C<created_at> (integer, required) - The Unix timestamp, in seconds, when the provenance check was created.

=item * C<object> (ProvenanceCheckObject, required) - The object type. Always C<content_provenance_check> for this endpoint.

See L</ProvenanceCheckObject> below for shape.

=item * C<results> (array of object, required) - The provenance results that apply to the uploaded file. Image results include
C2PA and SynthID; audio results include SynthID.

=back
