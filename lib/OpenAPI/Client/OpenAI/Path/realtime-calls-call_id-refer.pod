=head1 NAME

OpenAPI::Client::OpenAI::Path::realtime-calls-call_id-refer - Documentation for the /realtime/calls/{call_id}/refer path.

=head1 DESCRIPTION

This document describes the API endpoint at C</realtime/calls/{call_id}/refer>.

=head1 PATHS


=head2 C<POST /realtime/calls/{call_id}/refer>

Refer call


Transfer an active SIP call to a new destination using the SIP REFER verb.



=head3 Operation ID

C<refer-realtime-call>

    $client->refer-realtime-call( ... );

=head3 Parameters

=over 4

=item * C<call_id> (in path) (Required) - The identifier for the call provided in the
[`realtime.call.incoming`](https://platform.openai.com/docs/api-reference/webhook-events/realtime/call/incoming)
webhook.

Type: C<string>



=back

=head3 Request Body
  
=head3 Content Type: C<application/json>

    
      Parameters required to transfer a SIP call to a new destination using the
Realtime API.

      
      
Example:

    {
       "target_uri" : "tel:+14155550123"
    }


             

=head3 Responses


=head4 Status Code: C<200>

Call referred successfully.
