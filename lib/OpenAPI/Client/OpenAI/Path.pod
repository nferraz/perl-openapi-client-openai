Creates a model response for the given chat conversation. Learn more in the
L<text generation|https://platform.openai.com/docs/guides/text-generation>, L<vision|https://platform.openai.com/docs/guides/vision>,
and L<audio|https://platform.openai.com/docs/guides/audio> guides.

Parameter support can differ depending on the model used to generate the
response, particularly for newer reasoning models. Parameters that are only
supported for reasoning models are noted below. For the current state of
unsupported parameters in reasoning models,
L<refer to the reasoning guide|https://platform.openai.com/docs/guides/reasoning>.

=head2 C</files>

=over

=item * C<GET> - Returns a list of files.


=item * C<POST> - Upload a file that can be used across various endpoints. Individual files
can be up to 512 MB, and each project can store up to 2.5 TB of files in
total. There is no organization-wide storage limit. Uploads to this
endpoint are rate-limited to 1,000 requests per minute per authenticated
user.

=over

=item -

The Assistants API supports files up to 2 million tokens and of specific
  file types. See the L<Assistants Tools guide|https://platform.openai.com/docs/assistants/tools> for
  details.


=item -

The Fine-tuning API only supports C<.jsonl> files. The input also has
  certain required formats for fine-tuning
  L<chat|https://platform.openai.com/docs/api-reference/fine-tuning/chat-input> or
  L<completions|https://platform.openai.com/docs/api-reference/fine-tuning/completions-input> models.


=item -

The Batch API only supports C<.jsonl> files up to 200 MB in size. The input
  also has a specific required
  L<format|https://platform.openai.com/docs/api-reference/batch/request-input>.


=item -

For Retrieval or C<file_search> ingestion, upload files here first. If
  you need to attach multiple uploaded files to the same vector store, use
  L<C</vector_stores/{vector_store_id}/file_batches>|https://platform.openai.com/docs/api-reference/vector-stores-file-batches/createBatch>
  instead of attaching them one by one. Vector store attachment has separate
  limits from file upload, including 2,000 attached files per minute per
  organization.


=back

Please L<contact us|https://help.openai.com/> if you need to increase these
storage limits.


=back

See L<OpenAPI::Client::OpenAI::Path::files> for more details.
